Glossary of Key Terms

Definitions of acronyms and terms used throughout Modules 1–9, in alphabetical order.

Access Level
A Destiny security profile (e.g., Administrator, Teacher, Patron, Guest) that determines which tabs, sub-tabs, and permissions a user can see and use.
CIC (Class Import Converter)
A utility that converts SIS class-schedule exports into XML format for automated upload into Destiny, linking course sections to teacher records.
COPPA
Children's Online Privacy Protection Act — U.S. federal law restricting collection of personal information from children under 13.
CREW / MUSTIE
A collection-weeding methodology (Continuous Review, Evaluation, and Weeding) using the MUSTIE criteria — Misleading, Ugly, Superseded, Trivial, Irrelevant, Elsewhere — to identify deselection candidates.
DDC (Dewey Decimal Classification)
The numeric classification system used to organize non-fiction call numbers on the shelf.
EE / TOK
Extended Essay / Theory of Knowledge — IB Diploma Programme components that often require curated library Resource Lists and citation support.
FERPA
Family Educational Rights and Privacy Act — U.S. federal law protecting the privacy of student education records, including library circulation history.
ILL (Interlibrary Loan)
A workflow for requesting and transferring materials between school or library buildings within a district.
LCCN
Library of Congress Control Number — a standard identifier used to retrieve existing bibliographic records via Z39.50.
LDAP
Lightweight Directory Access Protocol — a directory-service protocol (e.g., Active Directory) that can automate Destiny access-level and patron-type provisioning.
LTI
Learning Tools Interoperability — the integration standard that lets Destiny content be embedded inside an LMS such as Canvas or Schoology.
MARC / MARC 21
Machine-Readable Cataloging — the standardized metadata format underlying every Destiny bibliographic (title) record.
OneRoster
An open API standard used to stream live roster and course-schedule data between a Student Information System and Destiny.
PIC (Patron Import Converter)
A standalone utility that converts raw SIS patron CSV exports into Destiny-compliant XML for bulk import.
PII
Personally Identifiable Information — data such as student names, addresses, or contact details that access-level permissions are designed to protect.
QRG
Quick Reference Guide — a short, official Follett how-to document, typically distributed as a PDF via Follett Community.
SIS
Student Information System (e.g., PowerSchool, Infinite Campus, Skyward, Aeries) — the system of record for enrollment and scheduling data that feeds Destiny.
SSO
Single Sign-On — authentication that lets users log into Destiny using existing Google Workspace or Microsoft Entra ID / Azure AD credentials.
VersaScan
Follett's handheld/mobile scanning hardware and app used for wireless circulation and inventory barcode scanning.
WCAG
Web Content Accessibility Guidelines — the standard (Destiny conforms to WCAG 2.1 AA) governing screen-reader support, keyboard navigation, and other accessibility features.
Z39.50
A standard search protocol Destiny uses to query external library catalogs (e.g., Library of Congress) for existing MARC records before manual cataloging.
