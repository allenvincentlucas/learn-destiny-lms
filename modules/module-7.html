Welcome to Module 7: Reporting, Dashboards & Data Analytics of the Follett Destiny Library Management System (LMS) training program. Updated for Destiny 24.0 / 23.5, this module details preconfigured reporting tools, custom report creation with Report Builder 2.0, and visual analytics dashboards (Follett Community, "Destiny 23.5 Readiness Kit").

Data-driven decision making empowers librarians to evaluate collection usage, justify budget allocations, identify weeding needs, and communicate library impact to school leadership (Mrs H Media, "Uncirculated Books").

What You'll Learn

  • Generate a preconfigured circulation, overdue/fine, or title/copy-list report from the correct Reports menu location.
  • Build and export a custom query using Report Builder 2.0.
  • Schedule an automated recurring report (e.g., weekly overdue digest).
  • Curate an EE/TOK Resource List and export MLA/APA-formatted citations for IB accreditation purposes.
  • Identify the correct export path (XML/Excel, OneRoster API, or command-line utility) for a given external BI or SIS integration need.

2. Reports, Custom Builder & Visual Analytics

A. Preconfigured Reports (Reports > Library Reports or Reports > Resource Reports)

  • Circulation Reports: Circulation statistics by Dewey class, patron type, grade level, or call number prefix (Follett School Solutions, "Collection Statistics").
  • Overdue & Fine Notices: Generating individual or homeroom overdue notices and unpaid fine summaries (Wuensch-Harden; Mrs H Media, "Classroom Reports").
  • Title & Copy Lists: Generating lists of lost books, titles with holds, or uncirculated items for collection weeding (Mrs H Media, "Uncirculated Books"; Follett School Solutions, "Generate a Title & Copy List").

B. Report Builder 2.0 (Destiny 24.0 / 23.5)

  • Modernized All-In-One Builder: An upgraded drag-and-drop custom reporting interface introduced in Destiny 23.5/24.0 allowing librarians to design, preview, and export custom data queries across Library Manager and Resource Manager (Follett Community, "Destiny 23.5 Readiness Kit").
  • Automated Report Scheduling: Scheduling recurring custom reports (e.g., weekly overdue digests) sent automatically to administrative email inboxes (Follett Community, "Destiny 23.5 Readiness Kit").

C. District & Site Dashboards

D. Accreditation, IB EE/TOK Source Usage & External Data APIs

  • Accreditation & Audit-Ready Report Templates:
    • TitleWise Collection Evaluation: Submits catalog data directly to TitleWise to produce comprehensive collection age, subject balance, and diversity gap analyses for accreditation boards (Follett Community, "Prepare for End of School Year").
    • Audit-Ready Asset Valuation: Generates net asset valuation and depreciation summaries under Reports > Resource Reports > Resource Value and Reports > Library Reports > Title & Copy List (Follett Software, "Resource Value Report").
  • IB Extended Essay (EE) & Theory of Knowledge (TOK) Source Usage Reporting:
    • Resource List Citation Exports: Librarians curate dedicated Resource Lists for EE/TOK research topics, automatically generating MLA/APA formatted citations directly from Destiny (Reports > Library Reports > Resource Lists) (Follett Software, "Use Resource Lists").
    • One Search & Database Usage Analytics: Tracks student utilization of subscription academic databases and non-fiction research collections to verify source diversity for IB accreditation audits (Follett School Solutions, "New to Destiny").
  • Data Export & API Paths for External Dashboarding:
    • Report Builder 2.0 XML & Excel Exports (Reports > Report Builder): Custom report queries can be saved, run automatically, and exported directly as XML or native Microsoft Excel (.xlsx) files for ingestion into external BI dashboard tools like Microsoft Power BI, Tableau, or Google Looker Studio (Follett School Solutions, "Report Builder").
    • Command-Line Data Extraction Utilities: Command-line utilities in \FSC-Destiny\fsc\bin (e.g. ExportFines.exe) extract district-wide fine and transaction logs for central data warehousing (Follett Software, "Export and import fine data").
    • OneRoster REST API & MARC 21 Exports: Streams live roster data via OneRoster API endpoints and exports MARC 21 bibliographic files (Catalog > Export Titles) for district LMS integration (Follett School Solutions, "Export Titles").
  • Visual Data Analytics: Graphical dashboard widgets presenting real-time circulation velocity, top-circulating titles, collection age analysis, and digital reading trends (Follett Community, "Destiny 23.5 Readiness Kit").

Q1. Which tool would a librarian use to build a custom, drag-and-drop query across Library Manager and Resource Manager data?

  • A. Collections by Destiny
  • B. Report Builder 2.0
  • C. Patron Import Converter
  • D. WebPath Express

Correct answer: B

Q2. A librarian needs a list of titles with zero circulations over the past three years to plan weeding. Which report category covers this?

  • A. Overdue & Fine Notices
  • B. Title & Copy Lists (uncirculated items)
  • C. Collection Statistics — Historical
  • D. Resource Value Report
Show answer
Correct answer: B

Q3. Which export format allows Report Builder 2.0 data to be ingested directly into tools like Power BI or Tableau?

  • A. .txt only
  • B. XML or native Excel (.xlsx)
  • C. PDF only
  • D. MARC 21 only
Show answer
Correct answer: B

Q4. What is the primary purpose of curating a Resource List for an IB Extended Essay topic?

  • A. To automatically generate MLA/APA citations and track source-diversity for accreditation audits
  • B. To restrict which students can check out fiction
  • C. To calculate patron fines
  • D. To configure the self-checkout kiosk
Show answer
Correct answer: A

Q5. A principal wants overdue notices emailed automatically every Monday without staff manually running the report. What Destiny 23.5/24.0 feature enables this, and where is it configured?

Show key points
Report Builder 2.0's automated report scheduling feature, configured under Reports > Report Builder, allows recurring reports (e.g., weekly overdue digests) to be scheduled and sent automatically to administrative email inboxes.

Q6. Explain how TitleWise Collection Evaluation supports IB accreditation reporting beyond simple circulation counts.

Show key points
TitleWise submits catalog data to produce collection age, subject balance, and diversity gap analyses — giving accreditation boards evidence of curriculum-aligned, current, and balanced holdings, not just circulation activity.
