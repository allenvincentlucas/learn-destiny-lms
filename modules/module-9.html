Welcome to Module 9: System Updates & Ongoing Professional Learning of the Follett Destiny Library Management System (LMS) training program. This final module covers tracking Destiny software release cycles (Destiny 23.5 & 24.0), utilizing release readiness kits, engaging with Follett Community, and pursuing continuous professional development (Follett Software, "Destiny 24.0: Product Updates").

Continuous professional learning ensures librarians stay informed on platform innovations, leverage new AI-driven capabilities, and continuously optimize library management for their schools (Follett Software, "Follett Academy Training").

What You'll Learn

  • Locate and interpret a Destiny release Readiness Kit before a district upgrade.
  • Use Follett Community and Follett Academy/myTrailhead for ongoing professional development.
  • Access context-sensitive in-product help and submit a technical support ticket through the correct channel.
  • Explain the difference between cloud-managed and on-premise Destiny backup/disaster-recovery procedures.
  • Apply the change-management framework (readiness review, staff training, sandbox practice) before a live software rollout.
Follett Destiny Overview — Scott Martin-Rowe

2. Software Release Cycles & Professional Learning Ecosystem

A. Tracking Destiny Release Cycles (Destiny 23.5 / 24.0)

  • Release Readiness Kits: Reviewing official readiness documentation prior to district upgrades to prepare staff for new feature rollouts (Follett Community, "Destiny 24.0 Readiness Kit").
  • Key Version Release Highlights:
    • Destiny 23.5: Report Builder 2.0 for Library Manager, Title Maintenance for easier digital-title weeding, site-level ILL permissions, and Kiosk Mode for Destiny Discover (Follett Software, "Introducing Destiny 23.5").
    • Destiny 24.0: Integrated Library AI Assistant updates, Patron Management 2.0, Holds and Interlibrary Loans 2.0, and Report Builder 2.0 extended to Resource Manager (Follett Software, "What's Coming").

B. Follett Community & Follett Academy

  • Follett Community Portal: Accessing user forums, product announcements, quick reference guides (QRGs), webinars, and feature request idea boards (Follett Software, "Follett Academy Training").
  • Follett Academy & myTrailhead: Self-paced gamified learning trails where educators earn digital badges and certificates for mastering library management workflows (Follett Software, "Follett Academy Training").

C. In-Product Support & Help Desk Services

  • Just-In-Time Help: Accessing context-sensitive in-product help by clicking the Help header link from any Destiny page (Follett School Solutions, "New to Destiny").
  • Technical Support: Submitting customer service tickets, reviewing downtime notices, and accessing release notes (Follett Community, "Destiny 24.0 Readiness Kit").

D. Disaster Recovery, Vendor SLAs & Staff Change Management

  • Disaster Recovery & Data Backup Procedures:
    • Follett Cloud Managed Backups: Automatically managed nightly cloud backups, off-site geo-redundancy, and point-in-time database recovery for cloud customers (Follett Software, "Destiny System Backups").
    • On-Premise Backup Plan: For self-hosted servers, districts implement full recovery model SQL Server backups, transaction log backups, directory encryption (\FSC-Destiny), and periodic backup restore testing (Follett Software, "Destiny System Backups").
  • Vendor Support SLA & Escalation Paths:
    • Technical Support Channels: Follett Technical Support is available via toll-free phone (1-800-323-3397 or 888-511-5114 Option 2), email (techsupport@follettsoftware.com), or online ticket submission through Follett Community (Follett Software, "Software Support").
    • Operating Hours & Priority 1 Escalation: Standard support operates 7:00am – 7:00pm ET, with 24/7 emergency escalation for Priority 1 system-down outages (Follett Software, "Software Support").
  • Change Management Framework for Software Rollouts:
    • Pre-Upgrade Planning & Communication: Review version Readiness Kits (e.g. Destiny 23.5 / 24.0 Kits), publish maintenance downtime notices, and communicate feature updates to school leadership (Follett Community, "Destiny 24.0 Readiness Kit").
    • Staff Onboarding & Training Execution: Utilize Follett Academy / myTrailhead gamified learning trails, distribute Quick Reference Guides (QRGs), and conduct hands-on sandbox practice before live deployment (Follett Software, "Follett Academy Training").

4. Practical Hands-On Learning Activities

  • Activity 9.1 - Exploring Follett Community: Register for an account on Follett Community, join the Destiny Library Manager discussion group, and bookmark the Destiny 24.0 Readiness Kit page (Follett Community, "Destiny 24.0 Readiness Kit").
  • Activity 9.2 - Accessing In-Product Help: From Destiny Back Office, click the Help link in the top header, use the search bar to look up "Offline Circulation", and review the resulting step-by-step topic guide (Follett School Solutions, "New to Destiny").
  • Activity 9.3 - Professional Learning Plan: Review the training trails on Follett Academy Training, select one self-paced module (e.g. Advanced Cataloging or Inventory Mastery), and establish a personal learning goal for the school year (Follett Software, "Follett Academy Training").

Q5. A district is about to upgrade from 23.5 to 24.0. Outline the recommended change-management sequence from readiness review through go-live.

Show key points
Review the Readiness Kit, publish maintenance downtime notices and communicate feature updates to leadership, use Follett Academy/myTrailhead trails and QRGs for staff training, conduct hands-on sandbox practice, then deploy live.

Q6. Explain the difference between Follett Community and Follett Academy, and when a librarian would use each.

Show key points
Follett Community is the user forum/announcements/QRG/idea-board hub for news and peer discussion; Follett Academy (myTrailhead) is the self-paced, gamified training platform with badges/certificates — use Community to stay current on releases and Academy to build or certify skills.
