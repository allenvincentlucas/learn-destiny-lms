Module 1: Orientation & System Navigation

Get fluent in the Destiny interface: the four core Back Office tabs, SSO login, mobile apps, and the accessibility features your students rely on.

Welcome to Module 1: Orientation and System Navigation of the Follett Destiny Library Management System (LMS) training program for school librarians, updated for the latest Destiny 24.0 / 23.5 software release. This module is designed to provide new school librarians with a foundational understanding of the Destiny ecosystem, its modernized user interface, AI-assisted capabilities, and core administrative features (Follett Software, "Destiny 24.0: Product Updates").

Follett Destiny is a cloud-hosted system, so librarians, teachers, and families can all reach it from a browser without installing local software (Follett School Solutions). In the latest release, Destiny incorporates integrated AI support and enhanced workflows across two primary operational environments (Follett Software, "What's Coming"):

  • Destiny Library Manager: A comprehensive library automation platform designed for managing print collections, digital subscriptions, eBooks, audiobooks, cataloging records, and patron circulation, now featuring the Library AI Assistant — a conversational assistant librarians can query for collection insights, weeding and purchasing worklists, and ready-to-share reports (Follett Software, "Library AI Assistant").
  • Destiny Resource Manager & IT Asset Manager: A district-wide asset tracking tool structured hierarchically to manage non-literary school equipment, including 1-to-1 student laptops, musical instruments, science kits, sports gear, and textbook inventories, complete with eSignature tracking for transfers (Follett Software, "What's Coming").

What You'll Learn

  • Distinguish between Destiny Library Manager and Destiny Resource Manager and identify which platform handles a given task.
  • Navigate the four Back Office tabs (Catalog, Circulation, Reports, Admin) and locate a specified feature within each.
  • Log in via SSO and troubleshoot a basic "Invalid Username" claim-mismatch error.
  • Identify the correct Destiny mobile app (Discover, Back Office, or VersaScan) for a given staff or student task.
  • Explain how Destiny's WCAG 2.1 AA accessibility features support students who use screen readers or keyboard-only navigation.

2. Getting Around Destiny: Interface and Main Navigation Tabs

Logging into Destiny places administrators and librarians in the modernized Destiny Back Office or redirects users to the student-facing Destiny Discover portal (LeDoux). The Back Office consists of four primary top-level tabs, optimized in Destiny 24.0 for faster navigation and mobile accessibility (Follett Community, "Destiny 23.5 Readiness Kit"):

  • 1. Catalog Tab:
    • Search options for print materials, eBooks, and digital databases, with filters by format, subject, and availability (Follett Community, "News").
    • Cataloging features for creating and editing title and item records, sourced from Alliance Plus or built manually in MARC (see Module 4).
    • Title Details View: A mobile-friendly display showing Accelerated Reader levels, series data, and title availability at a glance (Follett Community, "Destiny 23.5 Readiness Kit").
    • Integrated One Search and WebPath Express tools for curated internet research links (Follett School Solutions).
  • 2. Circulation Tab:
    • Core desk operations: Checking out, checking in, and renewing items.
    • Processing patron hold requests and interlibrary loans (ILL) with enhanced offline circulation support (Follett Community, "News").
    • Managing patron fines, overdue notices, eSignatures for resource transfers, and class rosters (Follett Software, "What's Coming").
  • 3. Reports Tab:
    • Report Builder 2.0: An all-in-one modernized interface to build, preview, automate, and export custom reports with advanced filtering features across Library Manager and Resource Manager (Follett Community, "Destiny 23.5 Readiness Kit").
    • Preconfigured report templates for circulation statistics, inventory summaries, and patron lists.
    • District and site-level visual dashboards for real-time library data analytics (Follett Community, "Destiny 23.5 Readiness Kit").
  • 4. Admin Tab:
    • Site configuration settings, calendar business days, and holiday closures.
    • Access levels, user security roles, and password administrative controls.
    • Import/export utilities for student and staff patron data, integrated with district SIS rosters.

Module 1 Supplement: Authentication, System Compatibility, Mobile Apps & Accessibility

A. Single Sign-On (SSO) & Login Troubleshooting

To streamline user access, Destiny supports multiple Single Sign-On (SSO) integration strategies (Setup > Sites > SSO Configuration) (Follett School Solutions, "Single Sign-On"):

  • Supported SSO Providers: Google Workspace for Education (google-signin), Microsoft Entra ID / Azure AD (SAML 2.0 / OAuth), ClassLink, Clever, and LTI integrations for Canvas and Schoology (Follett School Solutions, "Single Sign-On").
  • Google & Microsoft Setup: Administrators configure Client IDs and Secrets, applying Domain Filters (e.g. @school.com) to align external email claims with Destiny usernames or District IDs (Follett School Solutions, "Single Sign-On").
  • Login Troubleshooting & Password Recovery:
    • Claim Mismatch: If users encounter "Invalid Username" errors during SSO, verify domain filters and ensure the Destiny Field is correctly mapped to District ID or Username (Follett School Solutions, "Single Sign-On").
    • Password Reset Flow: For SSO accounts, passwords must be reset via Google or Microsoft account management. For local Destiny accounts, Site Administrators reset credentials under Admin > Manage Patrons, or patrons utilize the "Forgot Password" self-service recovery link if patron email notifications are enabled (Follett School Solutions, "Single Sign-On").

B. System Requirements & Device Compatibility

Destiny operates across web browsers, Chromebooks, workstations, and mobile devices (Follett Software, "Destiny System Requirements – Workstation"):

  • Display Resolution: Recommended resolution of 1366 x 768 (minimum 1024 x 768) (Follett Software, "Destiny System Requirements – Workstation").
  • Supported Web Browsers:
    • Windows 10/11: Google Chrome, Microsoft Edge, Mozilla Firefox.
    • macOS (10.13 to 15.0+): Apple Safari (v15.4+), Google Chrome, Mozilla Firefox.
    • Chrome OS: Native Google Chrome browser on Chromebooks.
    • Tablets/Mobile: iOS 15–18+ (Safari v15.4+, Chrome), Android 7.0–15.0+ (Chrome) (Follett Software, "Destiny System Requirements – Workstation").

C. Destiny Mobile Applications Overview

Follett provides native mobile tools for students, faculty, and library staff:

  • 1. Destiny Discover App (iOS / Android): Allows students and teachers to search print/digital catalogs, check out and download Follett eBooks and audiobooks for offline reading, view due dates, and manage holds (Follett Software, "Access the Destiny Discover App").
  • 2. Destiny Back Office App (iOS / Android): Mobile circulation powerhouse for librarians and staff (requires Destiny v19.3+), converting smartphones and tablets into wireless circulation desks for mobile checkouts, check-ins, and inventory scanning (Google Play, "Destiny Back Office App").
  • 3. VersaScan Scanner: Handheld hardware scanner equipped with the Back Office app for high-volume inventory audits, real-time status checks, and eSignature transfer verification (Follett Software, "Set up the Destiny Back Office App").

D. Accessibility Features & WCAG Compliance

Follett Destiny is built to conform with WCAG 2.1 AA standards and Section 508 guidelines (detailed in Follett's Voluntary Product Accessibility Template / VPAT) (PSD Schools):

  • Screen Reader Compatibility: Screen-reader status messages utilize proper ARIA roles so system alerts, warnings, and checkout confirmations are announced via JAWS, NVDA, and VoiceOver (Follett Software, "Destiny 24.0: Product Updates").
  • Navigation & Visual Usability: Features full keyboard-only tab navigation, clear page titles, high-contrast themes, and scalable text sizing across Destiny Discover and Back Office (Follett Software, "Destiny 24.0: Product Updates").

4. Practical Hands-On Learning Activities

To complete Module 1, new librarians should perform the following hands-on exercises in their school's Destiny sandbox or live site:

  • Activity 1.1 - Log-In and System Tour: Log into Destiny Back Office, switch between the Catalog, Circulation, Reports, and Admin tabs, and test the new Title Details view on a sample book record (LeDoux; Follett Community, "Destiny 23.5 Readiness Kit").
  • Activity 1.2 - Report Builder 2.0 Exploration: Open the Reports tab, launch Report Builder 2.0, and explore creating a quick custom filter for active patron circulation statistics (Follett Community, "Destiny 23.5 Readiness Kit").
  • Activity 1.3 - Student Interface Exploration: Switch from Back Office to Destiny Discover to view the student catalog layout. Test a keyword search for a popular title, test the new reading engagement features in Destiny Engage, and review how digital eBooks and physical titles are displayed (Follett Software, "Getting Started"; Follett Community, "Destiny 23.5 Readiness Kit").
